# 5X Minds

3D pitch-deck website for 5X Minds: hands-on AI programs for college students (Python, LLMs, RAG, LangChain, LangGraph, Hugging Face, open-source and frontier models, fine-tuning, image models, AI-assisted coding, and career support).

- `index.html` is the live site (GitHub Pages serves it).
- `5x-minds.html` is the same page without the `<html>/<head>/<body>` wrapper, used for the Claude artifact preview.

To show the enrol button and contact details on the last slide, fill in `CONTACT` at the top of the script in `index.html`.

Navigate with the arrow keys, Page Up/Down, or the dots on the right.
